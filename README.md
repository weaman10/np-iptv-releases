# NP IPTV – uppdateringsfiler

Publikt repo med bara artefakter. Koden ligger i det privata `np-iptv`.

- `update.json` – senaste versionen (läses av appen vid "Sök uppdatering").
- APK:erna ligger som release-assets: `releases/download/v<version>/np-iptv-<version>.apk`.

Uppdateras av `scripts/publish-github.sh` i `np-iptv`.
